# HP Smart Tank 520/540 (USB) в macOS: печать и сканирование

*[English version](README.md)*

Для многофункционального устройства (далее — МФУ) **HP Smart Tank 520 / 540**,
подключаемого только по USB (модель 1F3W2A и её региональные варианты),
компания HP не выпускает драйверов для macOS. Настоящий проект обеспечивает
работу обеих функций устройства в современных версиях macOS исключительно
средствами открытого программного обеспечения:

* **печать** в цвете и в оттенках серого из стандартного диалога печати macOS
  с выбором качества («Обычное», «Наилучшее», «Фото 1200 dpi») и типа бумаги;
* **сканирование** в программах «Захват изображений» и «Просмотр», а также в
  разделе «Системные настройки → Принтеры и сканеры»: цвет, оттенки серого,
  чёрно-белый режим, от 75 до 1200 dpi, форматы JPEG и PDF.

Программное обеспечение HP, платные приложения и закрытые двоичные модули не
требуются.

> Проект не связан с компанией HP Inc. и не одобрен ею. Используйте на свой риск.

## Принцип работы

| Функция | Что МФУ предоставляет через USB | Что добавляет проект |
|---|---|---|
| Сканирование | Полноценный сервер протокола **eSCL** (AirScan), доступный только через интерфейс IPP поверх USB (далее — IPP-USB, класс 7/1/4). Печать по протоколу IPP через этот интерфейс **не** поддерживается. | Программа-мост `scanbridge.py` пересылает HTTP-запросы между локальным портом и указанным интерфейсом USB и объявляет сканер через Bonjour под именем *Smart Tank 520_540 series (USB)*. Мост работает как системная служба launchd (LaunchDaemon). См. раздел «[Почему не встроенный USB-сканер macOS](#почему-не-встроенный-usb-сканер-macos)». |
| Печать | Язык PCL3GUI2 через классический принтерный интерфейс (7/1/2). | Открытый фильтр **hpcups** из пакета HP Linux Imaging and Printing (далее — HPLIP) версии 3.25.8, собираемый непосредственно под macOS, описание принтера (PPD) из HPLIP и исправление ошибки, из-за которой не печатался чёрный цвет (см. [docs/hplip-bug-report.md](docs/hplip-bug-report.md)). Задания на устройство отправляет штатная система печати CUPS. |

## Требования

* macOS на процессоре Apple или Intel. Проверено на компьютерах с процессором Apple под
  управлением macOS 15.7.3 (полная установка: печать, сканирование, отключение и повторное
  подключение МФУ) и macOS 27.0.1, прошивка МФУ `LAP1CN2446AR`. Работа на компьютерах с
  процессором Intel и в версиях macOS ранее 15 ожидается, но не проверялась.
* **Инструменты командной строки** (Command Line Tools). Установщик сам
  предложит их установить, объём около 1 ГБ.
* Пароль администратора.
* Доступ в интернет во время установки: библиотеки libusb и libjpeg
  скачиваются и проверяются по зафиксированным контрольным суммам SHA-256.

## Установка

1. Подключите МФУ по USB и включите его.
2. Скачайте репозиторий (*Code → Download ZIP* и распакуйте архив) либо
   клонируйте его:
   ```bash
   git clone https://github.com/maximiliangrishin-collab/HP_Smart_Tank_500_MacOS.git
   ```
3. В программе «Терминал» выполните:
   ```bash
   cd HP_Smart_Tank_500_MacOS
   ./install.sh
   ```
   Если система сообщит об отсутствии инструментов командной строки, завершите
   их установку в открывшемся окне и запустите `./install.sh` повторно.
4. Напечатайте тестовую страницу:
   ```bash
   lp -d HP_Smart_Tank_520 tools/testpage.pdf
   ```
5. Откройте «Захват изображений» и выберите **Smart Tank 520_540 series (USB)**. В списке может
   присутствовать также **HP Smart Tank 520_540 series**: это собственный сканер macOS, который с
   данным МФУ не работает; его следует игнорировать.

Параметры установщика: `--no-scan` (только печать), `--no-print` (только
сканирование), `--queue-only` (повторно создать очередь печати, например если
при установке МФУ не было подключено), `--paper A4|Letter` (формат бумаги по
умолчанию; без параметра выбирается по региону macOS).

## Удаление

```bash
./uninstall.sh
```

## Устранение неполадок

* **Сканер не появляется или не сканирует.** Просмотрите журнал:
  `tail /Library/Logs/hp520-scanbridge.log`. Проверить сканирование в обход «Захвата
  изображений» можно так: остановите мост командой
  `sudo launchctl bootout system/org.hp520-macos.scanbridge`, выполните
  `sudo python3 -I /Library/Printers/HPSmartTank520/scan/scanbridge.py --test ~/Desktop/scan.jpg`,
  затем запустите мост снова:
  `sudo launchctl bootstrap system /Library/LaunchDaemons/org.hp520-macos.scanbridge.plist`.
  Параметр `--verbose` вместо `--test …` выводит каждый запрос «Захвата изображений».
* **Сообщения «Failed to open a connection to the device (-21345)» или «failed to complete the
  overview scan».** Выбран сканер *HP Smart Tank 520_540 series*; выберите вариант с *(USB)*.
* **Осталась старая очередь, созданная в «Принтерах и сканерах» (AirPrint/IPP), с зависшими
  заданиями.** Печатать на этом МФУ она не может. Удалите её: узнайте имя командой `lpstat -p`,
  затем выполните `cancel -a <имя>` и `sudo lpadmin -x <имя>`.
* **Очередь печати не создана.** При установке МФУ не было видно на шине USB.
  Подключите его и выполните `./install.sh --queue-only`.
* **Чёрный или иной цвет отсутствует даже на копии, сделанной самим МФУ.**
  Неисправность связана с печатающей головкой или чернилами, а не с драйвером.
  Запустите очистку головок с панели устройства.
* **Доступ к сканеру с других устройств сети.** Добавьте параметр `--lan` в
  аргументы службы в файле `/Library/LaunchDaemons/org.hp520-macos.scanbridge.plist`.
  В этом случае сканировать сможет любое устройство локальной сети.

## Почему не встроенный USB-сканер macOS

В macOS (отмечено в версиях 15.7 и 27.0) имеется собственная служба IPP-USB: для принтера, у
которого есть очередь CUPS, система создаёт задание launchd
`com.apple.print.ippusb.<производитель>.<модель>.<серийный номер>`, которое запускает
`/usr/libexec/ippusbd`. Служба занимает интерфейсы IPP-USB и объявляет сканер под именем
*HP Smart Tank 520_540 series*. С данным МФУ этот путь неработоспособен: прошивка время от
времени выдаёт лишний HTTP-ответ, `ippusbd`, по всей видимости, не восстанавливает
синхронизацию, и в дальнейшем каждый запрос получает ответ на предыдущий (например, на запрос
`ScannerStatus` возвращается документ `ScannerCapabilities` объёмом 5384 байта). «Захват
изображений» в результате сообщает об ошибках -9921, -21345 или о невозможности выполнить
предварительное сканирование.

Мост перед каждым запросом удаляет такие устаревшие данные. Чтобы удерживать МФУ, он
занимает все три интерфейса IPP-USB, а при обнаружении, что интерфейсы заняты, снимает
указанное задание launchd для принтеров HP (для этого служба выполняется с правами root).
Мост объявляет собственный UUID, поскольку «Захват изображений» объединяет сканеры с
одинаковым UUID и в противном случае показывал бы только сканер macOS. Скрипт
`tools/test-native-escl.sh` выполняет одно сканирование через сканер macOS для сравнения.

## Устанавливаемые файлы

* `/Library/Printers/HPSmartTank520/` — фильтр `hpcups`, PPD и мост сканера;
* `/Library/LaunchDaemons/org.hp520-macos.scanbridge.plist` — запуск моста (с правами root);
* `/Library/Logs/hp520-scanbridge.log` — журнал моста;
* очередь CUPS `HP_Smart_Tank_520`.
