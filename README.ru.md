# HP Smart Tank 520/540 (USB) в macOS: печать и сканирование

*[English version](README.md)*

Для многофункционального устройства (далее — МФУ) **HP Smart Tank 520 / 540**,
подключаемого только по USB (модель 1F3W2A и её региональные варианты),
компания HP не выпускает драйверов для macOS. Настоящий проект обеспечивает
работу обеих функций устройства в современных версиях macOS исключительно
средствами открытого программного обеспечения:

* **печать** в цвете и в оттенках серого из стандартного диалога печати macOS
  с выбором качества («Обычное», «Наилучшее», «Фото 1200 dpi») и типа бумаги;
* **сканирование** в программах «Захват изображений» и «Просмотр», а также в
  разделе «Системные настройки → Принтеры и сканеры»: цвет, оттенки серого,
  чёрно-белый режим, от 75 до 1200 dpi, форматы JPEG и PDF.

Программное обеспечение HP, платные приложения и закрытые двоичные модули не
требуются.

> Проект не связан с компанией HP Inc. и не одобрен ею. Используйте на свой риск.

## Принцип работы

| Функция | Что МФУ предоставляет через USB | Что добавляет проект |
|---|---|---|
| Сканирование | Полноценный сервер протокола **eSCL** (AirScan), доступный только через интерфейс IPP поверх USB (далее — IPP-USB, класс 7/1/4). Печать по протоколу IPP через этот интерфейс **не** поддерживается. | В macOS 27 этот интерфейс, как правило, занимает встроенная системная служба `ippusbd`, которая сама объявляет сканер (*HP Smart Tank 520_540 series*); дополнительных средств не требуется. В противном случае ту же задачу выполняет программа-мост `scanbridge.py`: она пересылает HTTP-запросы между локальным портом и интерфейсом USB и объявляет сканер *Smart Tank 520_540 series (USB)* через Bonjour. Мост запускается службой launchd и бездействует, пока МФУ занято службой `ippusbd`. |
| Печать | Язык PCL3GUI2 через классический принтерный интерфейс (7/1/2). | Открытый фильтр **hpcups** из пакета HP Linux Imaging and Printing (далее — HPLIP) версии 3.25.8, собираемый непосредственно под macOS, описание принтера (PPD) из HPLIP и исправление ошибки, из-за которой не печатался чёрный цвет (см. [docs/hplip-bug-report.md](docs/hplip-bug-report.md)). Задания на устройство отправляет штатная система печати CUPS. |

## Требования

* macOS на процессоре Apple или Intel. Проверено на macOS 27.0.1 (процессор
  Apple) с прошивкой МФУ `LAP1CN2446AR`. Работа на компьютерах с процессором
  Intel и на более ранних версиях macOS ожидается, но не проверялась.
* **Инструменты командной строки** (Command Line Tools). Установщик сам
  предложит их установить, объём около 1 ГБ.
* Пароль администратора.
* Доступ в интернет во время установки: библиотеки libusb и libjpeg
  скачиваются и проверяются по зафиксированным контрольным суммам SHA-256.

## Установка

1. Подключите МФУ по USB и включите его.
2. Скачайте репозиторий (*Code → Download ZIP* и распакуйте архив) либо
   клонируйте его:
   ```bash
   git clone https://github.com/maximiliangrishin-collab/HP_Smart_Tank_500_MacOS.git
   ```
3. В программе «Терминал» выполните:
   ```bash
   cd HP_Smart_Tank_500_MacOS
   ./install.sh
   ```
   Если система сообщит об отсутствии инструментов командной строки, завершите
   их установку в открывшемся окне и запустите `./install.sh` повторно.
4. Напечатайте тестовую страницу:
   ```bash
   lp -d HP_Smart_Tank_520 tools/testpage.pdf
   ```
5. Откройте «Захват изображений» и выберите сканер МФУ: **HP Smart Tank 520_540 series** (предоставляется
   macOS) или **Smart Tank 520_540 series (USB)** (предоставляется мостом), в зависимости от того,
   какой из них присутствует в списке.

Параметры установщика: `--no-scan` (только печать), `--no-print` (только
сканирование), `--queue-only` (повторно создать очередь печати, например если
при установке МФУ не было подключено), `--paper A4|Letter` (формат бумаги по
умолчанию; без параметра выбирается по региону macOS).

## Удаление

```bash
./uninstall.sh
```

## Устранение неполадок

* **Сканер не появляется.** Просмотрите журнал:
  `tail ~/Library/Logs/hp520-scanbridge.log`. Проверить сканирование в обход
  macOS можно так: остановите мост командой
  `launchctl bootout gui/$(id -u)/org.hp520-macos.scanbridge`, выполните
  `python3 -I /Library/Printers/HPSmartTank520/scan/scanbridge.py --test ~/Desktop/scan.jpg`,
  затем запустите мост снова:
  `launchctl bootstrap gui/$(id -u) /Library/LaunchAgents/org.hp520-macos.scanbridge.plist`.
* **В журнале сказано, что МФУ занято службой `ippusbd` и мост бездействует.** Это штатная
  ситуация: сканер предоставляет сама macOS. Проверить его в обход «Захвата изображений» можно
  скриптом `tools/test-native-escl.sh`.
* **Осталась старая очередь, созданная в «Принтерах и сканерах» (AirPrint/IPP), с зависшими
  заданиями.** Печатать на этом МФУ она не может. Удалите её: узнайте имя командой `lpstat -p`,
  затем выполните `cancel -a <имя>` и `sudo lpadmin -x <имя>`.
* **Очередь печати не создана.** При установке МФУ не было видно на шине USB.
  Подключите его и выполните `./install.sh --queue-only`.
* **Чёрный или иной цвет отсутствует даже на копии, сделанной самим МФУ.**
  Неисправность связана с печатающей головкой или чернилами, а не с драйвером.
  Запустите очистку головок с панели устройства.
* **Доступ к сканеру с других устройств сети.** Добавьте параметр `--lan` в
  аргументы службы launchd. В этом случае сканировать сможет любое устройство
  локальной сети.

## Устанавливаемые файлы

* `/Library/Printers/HPSmartTank520/` — фильтр `hpcups`, PPD и мост сканера;
* `/Library/LaunchAgents/org.hp520-macos.scanbridge.plist` — запуск моста при входе в систему;
* очередь CUPS `HP_Smart_Tank_520`.
